What StarScanner Analyzes

Comprehensive auditing across four critical digital vectors.

Security & SSL Hygiene

Inspects SSL/TLS certificates, missing HTTP security headers (HSTS, CSP, X-Frame-Options), exposed admin endpoints, and mixed-content warnings.

Core Web Vitals & Speed

Measures Largest Contentful Paint (LCP), Cumulative Layout Shift (CLS), server response latency (TTFB), and unoptimized image payloads on real mobile networks.

Google Local Schema & SEO

Verifies JSON-LD structured data, Google Maps integration, OpenGraph social preview tags, and checks if the site is properly formatted for local search discovery.

Client Pitch Audit Reports

Outputs branded, easy-to-read audit scorecards. Perfect for freelancers paired with LeadsFlowPro to show local clients why their site is losing them money.

How a scan will work.

The shape is settled even though the build is not finished. Four steps, one URL in, one report out.

  1. Step 01

    Paste a URL

    Any public site. No access to the client's hosting, no plugin to install, no code for them to paste — everything checked is what a visitor's browser can already see.

  2. Step 02

    Load it like a phone would

    The page is rendered on a throttled mobile connection rather than a fast desktop one, because that is the connection the customer is actually on when they tap through from Google Maps.

  3. Step 03

    Check four areas

    Security headers and certificate, Core Web Vitals, structured data and local search signals, and broken or missing assets. Each finding is recorded with the evidence behind it.

  4. Step 04

    Get a report you can send

    A scorecard written for a shop owner rather than a developer, in language that says what is costing them customers instead of listing audit names they will not recognise.

Where the build actually is.

Plenty of products say "coming soon" and mean "we have a landing page". Here is the honest state of this one.

Working

Header and certificate inspection, and the Core Web Vitals capture. These are the checks I already run by hand on every site I build, which is where the idea for the tool came from.

In progress

Structured-data and local-search validation, and the asset crawl that finds broken images and dead links.

Not started

The branded PDF report, accounts and billing, and scan history. There is no launch date, because committing to one before this part exists would be a guess.

Questions about StarScanner.

When does it launch?

There is no announced date. Two of the four check groups work and the reporting layer does not exist yet. Joining the waitlist means you hear when it is real rather than when it is nearly real.

How is this different from PageSpeed Insights or Lighthouse?

It is not trying to beat them at measurement — Lighthouse is excellent and free, and StarScanner leans on the same vitals. The difference is the output. A Lighthouse report is written for a developer. StarScanner's is written to hand to a restaurant owner who needs to understand why their site is losing them bookings, and it adds the local-search and security checks Lighthouse does not cover.

Will it work on any website?

Any publicly reachable page. Sites behind a login, on an internal network, or blocking automated traffic cannot be scanned, and the report will say that rather than report a passing grade it could not verify.

What will it cost?

Not decided. Waitlist members are offered founder pricing when it does launch, but quoting a figure now for a product that is not finished would be a number I could not stand behind later.

Do you keep my client's data?

A scan reads a public page, so there is nothing private in it to begin with. Scan history is on the "not started" list above; when it is built, the retention rule will be written on this page before the feature ships, not after.
